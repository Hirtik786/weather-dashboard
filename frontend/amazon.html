Amazon Developer Console Setup Required

To enable live Login with Amazon on your local development machine, register a free Security Profile in the Amazon Developer Console and add the credentials to backend/.env:

1
Sign in to the Amazon Developer Console
Visit https://developer.amazon.com and log in with your regular Amazon account.
2
Create a Login with Amazon Security Profile
Go to Login with Amazon → Create a New Security Profile. Enter an Application Name and Consent Privacy Notice URL (e.g. http://localhost:5000/privacy.html).
3
Configure Web Settings
Under your Security Profile's Web Settings, click Edit and configure:
• Allowed JavaScript Origins: http://localhost:5000
• Allowed Return URLs: http://localhost:5000/api/auth/amazon/callback
4
Add Credentials to backend/.env
Copy your Client ID and Client Secret from the console into backend/.env:
LWA_CLIENT_ID=amzn1.application-oa2-client.your_client_id
LWA_CLIENT_SECRET=your_client_secret
LWA_REDIRECT_URI=http://localhost:5000/api/auth/amazon/callback
